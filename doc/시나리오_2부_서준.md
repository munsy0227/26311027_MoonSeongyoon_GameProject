| S47 | 기록철 첫 부분에는 사고 당시 교내 정리 작업 중 바닥 일부가 무너졌다는 내용이 남아 있다. 구조 과정과 학생 이동 기록은 뒤쪽 장에 적혀 있지만, 그 부분을 읽으려는 순간 교실 안의 그림자가 길어진다. |
| S48 | 그림자의 손처럼 보이는 검은 형체가 기록철 쪽으로 뻗는다. 아직 직접 공격하지는 않지만, 기록을 읽지 못하게 하려는 의도만큼은 숨기지 않는다. 서준은 검은 형체가 닿은 종이 가장자리가 가루로 부서지는 것을 본다. |
| S49 | 플레이어는 위험을 감수하고 기록을 읽을지, 기록을 놓고 그림자와 맞설지 선택한다. 기록을 읽으면 두 번째 핵심 단서를 얻는다. 기록을 놓는 경로에서는 읽지 못한 부분이 그림자의 손에 부서지고 다음 대치로 진행한다. |

### 선택 결과

#### I2-A — 기록을 끝까지 읽는다

- 핵심 단서 `사고 기록` 획득.
- 사건 점수 +20.
- 시스템 메시지: `사고 당일의 기록을 확인했다. +20점`
- 단서 메시지: `친구는 구조되었으나 서연은 교실에서 돌아오지 못했다는 기록이다.`
- D83A-D89A 출력 후 장면 6으로 진행.

#### I2-B — 기록을 놓고 그림자와 맞선다

- 기록 단서 미획득.
- 점수 변화 없음.
- D83B-D88B 출력 후 장면 6으로 진행.
- 전투 승리 후에도 자동으로 기록 단서를 얻지 않는다.

## 장면 6 — 교실 / 서연의 기억과 그림자의 정체

### 상황 설명

| ID | 상황 설명 |
|---|---|
| S50 | 기록을 읽었는지 여부와 관계없이 그림자는 교실 한가운데로 모습을 드러낸다. 복도에서 보였던 흐린 형체와 달리 이번에는 서연의 키와 비슷한 사람 모양을 취하고 있지만 얼굴은 끝까지 드러나지 않는다. |
| S51 | 서연은 그림자를 정면으로 보는 순간 자신이 그 목소리를 처음 들은 장소가 이 교실이었다는 사실을 떠올린다. 사고 직후가 아니라, 이미 자신이 이곳에 남은 뒤부터 ‘네가 버렸다’는 말이 반복되기 시작했다. |
| S52 | 서준은 이 차이를 이용해 그림자가 사고 당시 실제 인물이었는지 묻는다. 그림자는 대답하지 못하고 대신 서연이 품은 죄책감을 강조한다. |
| S53 | 사고 기록을 얻은 경우, ‘친구는 구조되고 서연은 돌아오지 못했다’는 객관적인 기록 때문에 그림자의 주장이 크게 흔들린다. 사진까지 가지고 있다면 행동과 결과가 서로 이어져 그림자의 설명은 더 좁아진다. |
| S54 | 기록이 없는 경우에도 서연은 복도에서 떠올린 기억을 바탕으로 의문을 제기한다. 친구와 함께 위험한 바닥을 피하고 문까지 데려간 기억은 ‘처음부터 친구를 버리고 혼자 도망쳤다’는 그림자의 말과 맞지 않는다. |
| S55 | 그림자는 자신이 서연의 기억을 만든 적은 없다고 주장한다. 대신 서연이 가장 두려워했던 생각을 계속 들려줬을 뿐이라고 말한다. 거짓 기억을 새로 만든 것이 아니라, 죄책감만 반복해 다른 해석을 못 보게 한 것이다. |
| S56 | 서연은 처음으로 그림자에게 직접 반박한다. 자신이 실제로 무엇을 했는지는 아직 완전히 모르지만, 그림자의 말이 자신의 기억 전체는 아니라는 점만큼은 인정한다. |
| S57 | 플레이어는 이 순간 서연에게 ‘기억을 같이 확인하자’고 말할지, 감정 대화를 미루고 그림자를 먼저 막을지 선택한다. 전자는 두 번째 공감 대화 선택으로 +10점을 얻는다. |
| S58 | 어느 선택을 하든 그림자는 서준이 서연의 판단 기준을 바꾸고 있다는 사실을 깨닫는다. 서연이 죄책감을 유일한 진실로 믿지 않게 되면 자신이 약해질 수밖에 없다는 점이 드러난다. |
| S59 | 그림자는 마침내 자신이 무엇인지 직접 말한다. 사고의 범인이나 죽은 학생의 혼이 아니라, 서연이 버리지 못한 두려움과 죄책감이 이 교실에 붙잡힌 채 형체를 얻은 존재다. |
| S60 | 서준은 그림자가 서연을 보호한다는 명분으로 사실상 서연이 떠나지 못하도록 붙들고 있었다고 지적한다. 그림자는 그 지적을 부정하지 못한 채 공격적인 형태로 변한다. |
| S61 | 교실 문이 스스로 닫히고, 검은 형체가 바닥과 벽을 타고 퍼진다. 그림자는 더 이상 대화로 조사를 멈출 수 없자 서준이 가진 증거부터 없애려 한다. |
| S62 | 서준은 서연에게 뒤로 물러나 있으라고 한다. 서연은 자신도 함께 맞서겠다고 하지만 직접 전투 능력은 없으므로, 대신 그림자가 흔들릴 때 기억과 단서를 확인해 주는 역할을 맡는다. |
| S63 | 같은 교실 배경과 인물 배치를 유지한 채 적 HP와 행동 예고가 나타난다. 마지막 전투가 시작된다. |

## 표시와 결말의 범위

전투 후 재조사나 이전 장소로 돌아가는 선택은 없다. 보관함을 지나치거나 기록을 놓는 선택은 해당 단서를 포기하는 선택이며, 기록을 놓으면 읽지 못한 부분이 훼손된다. 실패 결과 화면의 ‘다시 시작’은 새 게임이다.

결말은 좋은·보통·실패 3종이며 실패 대사만 단서 부족과 Life 소진으로 구분한다. 결과 화면은 하나를 공용으로 사용한다. 단서 2개와 승리의 기본 점수는 80점이다. 안전 통과 +20점 또는 공감 대화 두 번 +20점으로 100점에 도달하면 좋은 결말이다. 모든 선택이 A여야 좋은 결말이 되는 것은 아니다.
