# 3주차 구현 및 제출 기록

확인일: 2026-09-13 / 학번: 26311027 / 이름: 문성윤

## 구현한 범위

- glc2d 실제 화면에 복도 배경과 서연 RGBA 이미지 적용.
- 시작/종료 버튼, Enter/Space 시작, 프롤로그 8개 대사와 서연 첫 대화 18개 대사.
- C1 선택지 2개, 각 선택의 서준·서연 반응, 공감 선택 +10점(중복 지급 방지).
- 구현 구간 완료 안내, 타이틀 복귀, 새 게임 상태 초기화.
- 윈도우 크기에 비례하는 4:3 출력과 1920×1440 기준 클릭 판정.
- 실행 파일 위치 기준 리소스 로딩, 빌드 시 resource 자동 복사, 누락 시 오류 안내.
- 이미지 원본과 기존 게임의 최종 기획을 유지. 이미지 출처는 사용자 직접 AI 제작으로 기록.

## 강의 PDF 전체 기준과 남은 작업

이번 요청인 그래픽 준비·화면 출력·게임 시작 구현은 위 범위로 완료했다. 강의 PDF의 3주차 전체 기준에는 다음 미완료 항목이 있으므로 전체 만점 요건 완료로 표시하지 않는다.

- 탐색/전투 BGM 2종 및 선택/피해/회복 효과음 3종 준비·적용.
- 교실·그림자 이미지의 후속 장면 연결, 복도 조사·단서·장애물·전투·최종 결과 진행 구현.
- 최종 단계 전체 클래스/기능 구성 확정. 최신 구현 클래스 명세는 doc/게임기획서.md 17절에 추가했으며 기존 2주차 PDF는 갱신하지 않았다.
- 이전 테스트 이미지 정리 여부 검토. 원본 보존을 위해 이번 작업에서는 삭제하지 않았다.
