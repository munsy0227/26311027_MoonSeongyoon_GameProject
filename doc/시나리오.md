# 마지막 단서 시나리오

서준은 귀신을 보고 목소리를 듣는 학생이다. 폐교에서 서연을 만나 사진과 사고 기록을 조사하고, 서연의 죄책감에서 생겨난 그림자와 맞선다.

- [1부: 첫 만남과 복도 조사](시나리오_1부_서준.md)
- [2부: 교실 조사, 전투와 결말](시나리오_2부_서준.md)

## 게임 구성

장소는 복도와 교실 두 곳, 전투는 마지막 대결 한 번이다. 대화 분기는 선택·단서에 따라 짧게 갈라졌다가 본 줄거리로 합류한다. 한 번 지나친 조사로 돌아가는 기능은 없다. 결말은 좋은·보통·실패이며, 실패는 단서 부족과 Life 소진에 따라 대사를 구분한다.

## 표현 방식

고정 배경과 귀신 초상화, 텍스트, 효과음으로 진행한다. 프롤로그의 외부 풍경과 인물의 몸짓, 그림자의 움직임은 지문으로 전달한다. 초상화는 표시·교체·숨김만 사용하며, 장소 이동·붕괴·퇴장 애니메이션과 추가 배경은 사용하지 않는다. 대사와 지문은 한 화면에 최대 두 줄씩 나눈다.

## 점수와 분기

| 사건 | 점수 |
| --- | --- |
| 공감 대화 C1·C2 | 각각 +10 |
| 보관함 개방 | +20 |
| 사진·사고 기록 | 각각 +20 |
| 안전한 길 통과 | +20 |
| 전투 승리 | +20 |
| 합계 | 최대 120 |

사건 점수는 조사·공감·위험 대응의 합계다. 단서 2개와 전투 승리가 있는 상태에서 100점 이상은 좋은 결말, 100점 미만은 보통 결말이다. 단서가 부족하거나 Life가 소진되면 실패 결말이다.
