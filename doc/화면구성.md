# 화면 구성

최종 구현 기준: 2026-10-03. 1920×1440의 4:3 좌표를 사용한다. 아래 좌표는 실제 코드 기준이며 doc/screens의 과거 설계도와 구분한다.

| 화면 | 표시와 진행 |
| --- | --- |
| 시작 | 복도 배경·제목·시작·종료. 시작하면 새 게임 초기화 |
| 대화·조사 | 장소·단서·HP·Life·점수, 배경·인물·대화창·선택지 |
| 전투 | 같은 교실·인물 위에 적 HP·공격 예고·명령 4개. 결과·관계·예고는 대화창에서 확인 |
| 후속·결말 | 전투 UI를 숨기고 같은 교실에서 공통·분기 대사 진행 |
| 결과 | 복도 배경·결말 제목·설명·점수·단서 수, 다시 시작·종료 |

## 영역과 입력

| 영역 | 기준 좌표 |
| --- | --- |
| 상태 | (30,35)~(1460,215) |
| 메뉴 / 아이템 | (1510,35)~(1860,115) / (1510,135)~(1860,215) |
| 선택지 두 개 | (200,730)~(1720,840) / (200,870)~(1720,980) |
| 전투 명령 | y=850~970, x=90~510 / 530~950 / 970~1390 / 1410~1830 |
| 대화창 / 다음 | (90,1020)~(1830,1370) / (1460,1260)~(1830,1360) |
| 아이템·일시 정지 패널 | (410,360)~(1510,1080), 화면 전체에 반투명 가림 |
| 결과 다시 시작 / 종료 | (260,1060)~(920,1170) / (1000,1060)~(1660,1170) |

글꼴은 A2Z 6 SemiBold다. 안내·본문 28px, 화자·결과 요약 38px, 타이틀 96px를 화면 배율에 맞춰 생성한다. 긴 원고는 보수적 너비로 두 줄씩 페이지를 나눈다. 그리기는 실제 화면 크기, 클릭은 클라이언트 좌표를 기준 좌표로 변환한다.

## 패널과 선택

- 아이템: 회복약 수량·열쇠·사진·사고 기록. 닫기 버튼, Esc/I/Enter/Space 지원. 회복은 전투 명령에서만 사용.
- 일시 정지: 재개·게임 종료. 위·아래 + Enter, 숫자 1/2 또는 클릭. Esc로 재개.
- 두 패널은 동시에 열지 않는다. 열린 동안 뒤쪽 화면의 입력을 차단하고 여닫는 입력은 한 프레임에서 소비한다.
- 선택 위치는 금색 테두리, 비활성 명령은 회색과 이유로 구분한다. 명령을 쓸 수 없으면 턴을 소비하지 않는다.

## 이미지와 전환

서준은 1인칭 화자로 초상화가 없다. 서연·그림자는 각 고정 이미지 한 장을 사용하고 화자에 따라 밝기를 구분한다. 승리 퇴장 대사까지 그림자를 표시한 뒤 마지막 안내에서 숨긴다. 좋은·보통 결말의 서연 퇴장은 결과 장면 전환으로 표현한다. 새 애니메이션 프레임은 추가하지 않는다.

승패 확정 후 이야기 BGM으로 돌아간다. 공격·피해 효과음은 한 효과 적용 시 한 번, 회복은 회복 효과음, 진행·버튼은 클릭 효과음을 사용한다. 사진·기록·함정은 텍스트와 기존 효과음으로 표현한다.

`doc/screens/01_start.png`~`04_result.png`는 과거 설계도다. `doc/runtime`은 이전 실행 기록이며 최종 버전의 캡처나 화면 검증 증거로 사용하지 않는다. 최신 실행 확인표는 [Final.md](Final.md)에 있다.
