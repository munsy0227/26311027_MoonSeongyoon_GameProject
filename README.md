# 마지막 단서

**학번:** 26311027

**이름:** 문성윤

**과목명:** 객체지향프로그래밍Ⅰ

**과제명:** 게임제작 과제

귀신을 보고 대화할 수 있는 서준이 폐교의 사진과 사고 기록을 조사하고, 서연의 죄책감에서 생겨난 그림자와 맞서는 비주얼 노벨·선택형 턴제 전투 게임이다. 복도와 교실 두 장소, 전투 한 번, 좋은·보통·실패 결말로 구성한다. 실패 대사는 단서 부족과 Life 소진을 구분한다.

## 게임 기능

시작 → 프롤로그 → 서연과 대화 → 보관함·깨진 바닥·사고 기록 조사 → 전투 → 승리 후 대화 또는 Life 소진 대사 → 결말 → 결과 화면까지 연결했다. 결과 화면에서 다시 시작하거나 종료할 수 있다.

- 사진·기록 조합에 따른 단서 활용 대사, 명령별 반응, 적 공격 예고와 시도당 한 번 나오는 관계 변화 대사.
- 회복약·열쇠·사진·기록을 확인하는 아이템 패널, 재개·종료를 제공하는 일시 정지 메뉴.
- 같은 교실 화면에서 전투와 후속 대사 진행. 승패 확정 후 이야기 BGM으로 전환.
- 1920×1440 기준 4:3 화면.

## 조작

| 상황 | 조작 |
| --- | --- |
| 시작 | 시작 버튼, Enter 또는 Space |
| 대사·전투 결과 확인 | 다음 버튼, 대화창 클릭, Enter 또는 Space |
| 조사 선택 | 클릭, 숫자 1/2, 위·아래 + Enter |
| 전투 명령 | 클릭, 숫자 1~4, 위·아래 + Enter |
| 아이템 목록 | 아이템 버튼 또는 I. 닫기·Esc·I·Enter·Space로 닫기 |
| 일시 정지 | 메뉴 버튼 또는 Esc. 재개·종료 버튼, 숫자 1/2, 위·아래 + Enter |
| 일시 정지 해제 | Esc 또는 재개 |
| 결과 화면 | 다시 시작·종료 버튼, 숫자 1/2, 방향키 + Enter. Space로 다시 시작, Esc로 종료 |

패널이 열린 동안 뒤쪽 입력은 차단한다. 패널을 닫는 입력은 대사 진행이나 명령으로 전달하지 않는다. 아이템 목록에서는 보유 상태만 확인하며 회복약은 전투에서 사용한다.

## 규칙과 결말

- 시작: HP 100, Life 3, 점수 0, 단서 없음, 회복약 1개.
- 적 HP 100. 일반 공격 15와 강한 공격 25를 번갈아 예고.
- 공격: 적 HP -20. 방어: 이번 피해 10. 회복: 회복약 1개 소비, 최대 30 회복. 단서: 1개 이상 보유 시 시도당 한 번 적 HP -40.
- 사용 불가 명령은 턴을 소비하지 않는다. 피해·회복 메시지는 실제 적용량을 표시한다.
- HP 0에서 Life를 한 번 차감한다. Life가 남으면 조사 성과를 유지하고 HP 100·적 HP 100·회복약 1개·첫 턴으로 재도전한다.
- 승리 +20은 한 번만 지급하며 반격은 없다. 총점 상한은 120.

| 결말 | 조건 |
| --- | --- |
| 좋은 — 마지막 단서 | 승리 + 단서 2개 + 최종 점수 100 이상 |
| 보통 — 사실과 마음의 거리 | 승리 + 단서 2개 + 최종 점수 100 미만 |
| 실패 — 확인하지 못한 빈칸 | 승리 + 단서 0~1개 |
| 실패 — 여기서 멈추는 조사 | Life 0 |

다시 시작은 새 게임이다. HP·Life·점수·단서·아이템·대사·선택·전투·관계 대사 출력 기록·메뉴 상태를 초기화한다.

## 빌드 및 실행

1. Windows의 Visual Studio 2022에서 `26311027-MoonSeongyoon-VN/26311027-MoonSeongyoon-VN.sln`을 연다.
2. NuGet 패키지 복원: `glc2d 0.1.0.7`, `Microsoft.DXSDK.D3DX 9.29.952.8`.
3. **Debug / x64**로 빌드하고 F5로 실행한다.

빌드가 PNG·TTF와 MP3를 실행 폴더의 `resource/`에 복사한다. MP3는 영문 별칭으로 복사하며 원본 파일명을 유지한다. 실행 파일을 옮길 때는 `resource/`와 필요한 DLL도 함께 옮긴다. 에이투지체(A2Z 6 SemiBold)는 실행 중에만 등록한다.
